# Agent trial packet

Give another main agent MAIN_AGENT_PROMPT.md and this entire folder/ZIP. The prompt is complete and directs one fresh subagent per adult persona. No trial has been run in this packet.

Included: 150 stripped personality profiles; 146 adult respondent assignments; 54 complete questionnaire items; original symptom sheets; response contract; generation/validation instructions; a post-generation collector. No literature review, research gaps, hypotheses or target results are included.

Default run: 130 adult workers plus 16 exploratory adult staff; four minors excluded from the adult questionnaire. Every profile and response is fictional. This tests role-play and workflow, not whether real-world hypotheses are true.
